<h2 id="description" align="center">Description</h2>
Fox Dash, an endless runner inspired by Google's Dino Run built in Unity. Features simplistic art design and game design that seeks to emphasize consistency and challenge a player's reaction time.

- GIMP (UI & image alteration)
- BeepBox (Music & SFX)
